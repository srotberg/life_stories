# סיפורי חיים וביוגרפיות – רינה רוטברג

אתר וכרטיס ביקור דיגיטלי.

| קובץ | תיאור |
|---|---|
| `index.html` | כרטיס הביקור – תמונה, שם, אייקונים לרשתות ולדרכי יצירת קשר |
| `site.html` | האתר – טקסט מלא ואזור יצירת קשר, נכנס כולו למסך אחד |

## תמונות

מעלים לתיקייה הראשית בשמות המדויקים הבאים:

- `banner.jpg` – רקע כרטיס הביקור
- `hero.jpg` – רקע הכותרת באתר
- `rina.jpg` – תמונת הפורטרט בכרטיס הביקור

אם קובץ חסר, העמוד מציג ציור רקע חלופי במקומו – שום דבר לא נשבר.

## פרסום

Settings → Pages → Deploy from a branch → `main` → `/(root)`
